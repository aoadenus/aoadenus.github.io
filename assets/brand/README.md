# University of Houston brand assets

Retrieved October 11, 2026. These official assets are stored locally so the portfolio has no runtime dependency on a third-party logo or font server. Logos are unchanged files; the University of Houston retains its trademark rights. The portfolio is Adetutu Adenusi's personal site, not an official university website.

## Logo sources and use

- `uh-signature.png`: [official full-color horizontal signature](https://www.uh.edu/brand/_img/uh-horiz-full-color-rgb.png), 1600 × 332 px.
- `uh-signature-red.png`: [official red horizontal signature](https://www.uh.edu/brand/_img/uh-horiz-1-color-red-rgb.png), 1600 × 332 px.
- `uh-interlocking.png`: [official red interlocking mark](https://www.uh.edu/brand/_img/uh_red.png), 908 × 789 px.

The [UH Signature guidelines](https://www.uh.edu/brand/brand-identity/master-brand-logos-and-marks/uh-signature/) prefer the horizontal signature. Use the full-color signature on white, preserve its proportions and colors, and apply no filters, opacity, cropping, shadows, rotation or other treatments. Reserve clear space on each side equal to half the interlocking symbol's height. The horizontal signature should be at least 108 CSS pixels wide.

The [interlocking mark guidelines](https://www.uh.edu/brand/brand-identity/master-brand-logos-and-marks/interlocking-uh/) call for clear space equal to half the symbol's height and a minimum screen width of 36 pixels. The mark appears only alongside educational affiliation, not as the personal navigation identity.

The [UH student/faculty/staff usage policy](https://www.uh.edu/brand/brand-protection/uh-users/index) requires brand approval for external academic communications and marketing materials using the marks. This local implementation does not establish or claim that approval; confirm the applicable university approval before public use of these marks. The [Download Zone](https://www.uh.edu/brand/brand-resources/download-zone/) provides the university's full asset suite using CougarNet login.

## Theme references

[Brand Style Guide](https://www.uh.edu/brand/brand-identity/style-guide/) and [Web Style Guidelines](https://www.uh.edu/marcom/guidelines-policies/web-style/): red `#C8102E`, white `#FFFFFF`, black `#000000`, slate `#54585A`; supporting brick `#960C22`, cream `#FFF9D9`, and gold `#F6BE00`. Red and white are dominant, with accents used sparingly. Use League Gothic for large headings, Source Sans 3 for body and interface text, and Crimson Pro for selected editorial copy. Font size and contrast must remain readable across viewports.

## Local web fonts

Load `assets/fonts/fonts.css` once before the main stylesheet. Available font families:

- `League Gothic`: normal, 400. [Official UH WOFF2](https://www.uh.edu/fonts/leaguegothic-regular-webfont.woff2), linked by [UH fonts.css](https://www.uh.edu/css/fonts.css).
- `Source Sans 3`: normal, variable weights 400–700, Latin subset. [Google Fonts WOFF2](https://fonts.gstatic.com/s/sourcesans3/v20/nwpStKy2OAdR1K-IwhWudF-R3w8aZQ.woff2).
- `Crimson Pro`: normal 400 and italic 400, Latin subsets. [Regular WOFF2](https://fonts.gstatic.com/s/crimsonpro/v28/q5uUsoa5M_tv7IihmnkabC5XiXCAlXGks1WZzm1MP5s-.woff2) and [italic WOFF2](https://fonts.gstatic.com/s/crimsonpro/v28/q5uSsoa5M_tv7IihmnkabAReu49Y_Bo-HVKMBi6Ue6s8fNE.woff2).

Google font URLs were obtained from the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400;600;700&family=Crimson+Pro:ital,wght@0,400;1,400&display=swap).
